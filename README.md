# Python Learning Path

A practical, progressive path from Python fundamentals to AI/ML, LLM applications, agents, production architecture, MLOps, and technical interviews.

## Start here

1. Read [QUICKSTART.md](QUICKSTART.md).
2. Work through the modules in order.
3. Run the examples in each module's `examples/` directory.
4. Complete the practice tasks before moving forward.
5. Use [AUDIT_AND_RESOURCES.md](AUDIT_AND_RESOURCES.md) for the full topic and tool matrix.

## Modules

| # | Module | Main outcome |
|---:|---|---|
| 01 | [Basic Python](01-basic-python/README.md) | Learn Python syntax, data, control flow, and functions |
| 02 | [Automation and Scripting](02-automation-and-scripting/README.md) | Automate files, command-line tasks, and preprocessing |
| 03 | [Artificial Intelligence and Machine Learning](03-artificial-intelligence-and-machine-learning/README.md) | Understand data, NumPy, pandas, scikit-learn, and evaluation |
| 04 | [AI Agents and LLM Workflows](04-ai-agents-and-llm-workflows/README.md) | Understand prompts, tools, agents, and model workflows |
| 05 | [DevOps Automation](05-devops-automation/README.md) | Learn Docker, CI/CD, infrastructure, and operations |
| 06 | [Agentic AI](06-agentic-ai/README.md) | Design autonomous and multi-agent workflows |
| 07 | [LLM Project Patterns and Production Workflows](07-llm-project-patterns-and-production-workflows/README.md) | Build reliable, cost-aware LLM applications |
| 08 | [End-to-End Python AI Project Architecture](08-end-to-end-python-ai-project-architecture/README.md) | Organize an AI application into maintainable layers |
| 09 | [Production Deployment and MLOps](09-production-deployment-and-mlops/README.md) | Deploy, monitor, version, and operate AI services |
| 10 | [Real-World Python AI Capstone Project](10-real-world-python-ai-capstone-project/README.md) | Build a complete document-question answering service |
| 11 | [Advanced Python Engineering and Software Design](11-advanced-python-engineering-and-software-design/README.md) | Apply typing, patterns, async code, and clean architecture |
| 12 | [Interview Preparation and Coding Challenges](12-interview-preparation-and-coding-challenges/README.md) | Prepare for Python, AI, system-design, and coding interviews |

## Learning tracks

- **Python developer:** 01 → 02 → 11 → 12
- **ML practitioner:** 01 → 02 → 03 → 08 → 09 → 10
- **LLM application developer:** 01 → 02 → 04 → 07 → 08 → 10
- **AI platform engineer:** 03 → 05 → 06 → 08 → 09 → 11
