# Python Learning Path

A beginner-first Python course written in simple English.

## Learning rule

Every example explains:

- **What** the code is.
- **Why** we use it.
- What each important line does.
- How to make the example dynamic.
- Where the idea is used in real work.

## Learning order

1. Basic Python
2. Automation and scripting
3. Artificial intelligence and machine learning
4. DevOps automation
5. AI agents
6. Agentic AI and LLM applications

## Current module

- [01 - Basic Python](01-basic-python/README.md)

Advanced topics will be added after the basic Python foundation is complete.

## How to practise

1. Read one example.
2. Type it yourself instead of only copying it.
3. Run it with the original values.
4. Change at least three values.
5. Predict the output before running it.
6. Complete the practice task.
